What actually runs?

The baseline uses the standard TestBox HTML runner. The worker run uses the same Runner, Coordinator, and ProgressFile APIs as RUN and the CLI. A demo-owned provider launches one BoxLang JVM per worker. No results or worker events are simulated. Each spec includes a configurable 300 ms demonstration pause.
